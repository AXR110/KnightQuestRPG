This is a text-based RPG with a GUI based on classic text-adventure RPGs and Dragon Quest, programmed in Java using Java Swing.
-
-
Within the src folder, there should be two packages: "assets" and "system".
-
"assets" includes the monster superclass and subclasses, as well as the weapon superclass and subclasses: Monster_Dragon, Monster_Orc, Monster_Slime, MonsterSuperClass, Weapon_Dagger, Weapon_Sword, WeaponSuperClass.
-
"system" includes the classes that make the game work essentially: Game, Player, Story, UI, VisibilityManager.
-
There should also be an image (KnightQuestBackground.jpg) that will display a background for the entirety of the game. Otherwise, the background will simply be black.
-
The "Story" class uses logic to navigate the world as well as different outcomes based on the items you pick up, the enemies you defeat, and the places you have already visited.
